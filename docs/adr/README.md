## 형식

각 ADR은 다음 구조를 따릅니다.

- **맥락** — 어떤 상황에서 결정이 필요했는가
- **결정** — 무엇을 선택했는가
- **근거** — 왜 그 선택인가
- **감수하는 것** — 이 선택으로 포기하거나 떠안는 비용
- **되돌리는 비용** — 나중에 뒤집어야 할 때 얼마나 드는가

마지막 항목을 명시하는 이유는, 되돌리기 싼 결정은 빨리 내리고 비싼 결정에만 시간을 쓰기 위해서입니다.
